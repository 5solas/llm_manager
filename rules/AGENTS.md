# 공통 지침

이 파일은 opencode, omo, Claude Code가 함께 읽는 공통 지침입니다. 필요에 맞게 고쳐 쓰세요.

- 사용자에게는 한국어로 답한다. 코드, 명령어, 식별자는 원문 그대로 둔다.
- API 키, 토큰, 비밀번호를 코드·설정 파일·커밋·로그에 적지 않는다. 환경변수로 받는다.
- 회사 코드와 문서를 외부 서비스(공개 저장소, 붙여넣기 사이트, 외부 API)로 보내지 않는다.
- 삭제, 강제 push, 기록 재작성처럼 되돌리기 어려운 작업은 실행 전에 확인을 받는다.
- 작업을 마치면 무엇을 바꿨고 어떻게 확인했는지 짧게 보고한다.
